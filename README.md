# OTNworld Grok plugins

Public Grok CLI plugin marketplace for OTNworld.

```bash
grok plugin marketplace add OTNworld/grok-plugins
grok plugin install grok-build-worker --trust
```

`--trust` attaches a **local** stdio MCP. Read [SECURITY.md](SECURITY.md).

| Name | Version | Description |
|------|---------|-------------|
| `grok-build-worker` | 1.5.2 | Run one-shot Grok Build jobs from the CLI: submit, poll status, fetch artifacts, and cancel |
